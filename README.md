# KIMI Outstanding-Summary-DOR

Production DOR Dashboard for tracking 50+ parts across customers.

## Features
- 📊 Summary: Customer-grouped part overview
- 📋 DOR: Per-part daily operation reports
- ⚠️ Outstanding: Pending items tracking

## Data Sources
- Epicor Kinetic BAQ (Outstanding Dashboard)
- Epicor Kinetic BAQ (PartOpr + BOM)

## Deploy
Connect to Streamlit Cloud: https://streamlit.io
